# 설계 점검 기록

기준일: 2026-11-09  
상태: 사용자와 결정 사항을 확인하는 진행 중 기록임. 미구현 항목은 검증된 기능이 아님.

이 문서는 당시 결정의 기록임. 이후 사용자 요청에 따라 한글·Word 모바일 재배치 보기를 제거하고 원본 페이지 보기와 확대·축소를 우선함. 현재 기준은 `DESIGN.md`를 참고함.

## 합의된 범위

- 최소 Android 버전은 10(API 29)으로 함. 실기기의 실제 OS 버전 및 설치 여부는 미확인 상태임.
- 실기기 검증 대상은 갤럭시 탭 S10 울트라, 갤럭시 S26 울트라, 갤럭시 Z 플립8, 갤럭시 S25+임. 모델 표기는 사용자의 명칭을 따름.
- Office의 내용 보존을 우선하며 필요하면 더 큰 엔진을 앱에 포함함. 기기에서 오프라인으로 처리함.
- DOC·XLS·PPT는 1차 필수 형식 이후로 검증함.
- 한글과 Word의 원본 페이지 보기와 모바일 재배치 보기를 모두 1차 범위에 포함함. 원본 보기를 기본으로 하며 재배치에서 내용 누락 가능성을 알리고 원본 보기로 돌아갈 수 있도록 함.
- PDF·한글은 원본 페이지의 연속 스크롤을 기본으로 함. 두쪽 보기에서는 표지를 단독으로 표시함.
- PowerPoint는 한 슬라이드 보기를 기본으로 하고 전체 슬라이드 목록을 별도로 엶.
- 암호 문서는 엔진이 지원하는 형식부터 비밀번호를 기기에서 입력해 열도록 함.
- 사용자가 선택한 글꼴은 원본을 유지하고 앱 전용 복사본을 보관하며 목록과 삭제를 제공함.
- 표시 누락이 발견되면 이를 알리고 지원되는 다른 오프라인 엔진으로 여는 선택지를 제공함. 모든 누락을 자동 감지할 수 있는지는 미검증 상태임.
- 시작 화면은 파일 열기와 최근 문서를 제공하며 기기 전체를 자동 검색하지 않음. 최근 문서의 권한이 만료되거나 원본이 이동한 경우 파일 재선택을 안내함.
- 최근 문서의 파일명과 마지막 페이지·보기 방식을 기기에만 저장하고 개별·전체 삭제를 제공함. 표시 누락 가능성이 확인된 형식은 제한을 안내함.
- 테마는 시스템 설정을 기본으로 하고 앱에서 선택할 수 있도록 함. 책갈피보다 최근 위치 복원을 우선함.

## 확인된 문제와 대응 상태

| 구분 | 내용 | 상태 |
|---|---|---|
| PPTX 이미지 | OpenDocument.core 7.7.0은 공개 한국어 PPTX의 이미지를 출력하지 않음 | office-kit 시험 경로와 LibreOffice Viewer에서 이미지를 확인함. office-kit 제목 정렬 차이 및 Office 전체 품질 검증 필요 |
| Word 원본 배치 | 경량 경로의 공개 DOCX가 좁은 화면에 재배치됨. LibreOffice 시험 경로의 공개 DOCX 첫 페이지는 원본 페이지 형태로 표시됨 | 여러 페이지·표·그림·글꼴과 실문서 검증 필요 |
| 문서 전환과 오류 | 연속 열기의 결과 경합, 실패 시 이전 문서 잔상, 종료 후 콜백 가능성 | 요청 세대 검사와 화면 초기화를 추가함. Node 모의 테스트 통과, 에뮬레이터 경합 재현 시험 필요 |
| 파일 형식 | `.docx` 확장자를 붙인 텍스트가 이전에는 열림 | 엔진이 판별한 Office 형식과 확장자를 대조하도록 수정. 에뮬레이터에서 오류 표시 확인 |
| 한글 SVG | 문서에서 나온 SVG를 앱의 주 스크립트 문서에 직접 삽입함 | 스크립트를 허용하지 않는 sandbox iframe으로 격리함. 공개 HWP 첫 쪽 표시 확인; 보안 검증은 미완료 |
| 대용량 | WebView 입력 중복 복사 제거 및 LibreOffice의 앱 전용 임시 파일 스트리밍 적용. 약 25.36MB 합성 PPTX 열기 확인 | 엔진 내부 메모리 사용, 큰 이미지·복잡한 실제 문서 및 실기기 최대 메모리 검증 필요 |
| 화면 보기 | PoC는 단일 항목과 번호 목록만 제공함 | 연속·두쪽·모바일 보기, 썸네일, 확대 상태 복원, PDF/CSV 및 외부 앱 연결 미구현 |
| 비밀번호·글꼴 | 기능 범위가 새로 결정됨 | 암호 형식별 엔진 지원과 글꼴 가져오기·저장·적용·삭제 미구현 |
| 오프라인 | APK에 인터넷 권한 선언이 없음 | 에뮬레이터 비행기 모드, 외부 리소스 차단 및 실기기 시험 필요 |

## 남은 설계 질문과 확인

- 모바일 재배치에서 실제 누락을 어떤 수준까지 감지하고 대체 엔진이 동일 파일을 열 수 있는지 확인이 필요함.
- 암호 문서별로 지원 가능한 암호 방식과 실패 안내를 확인해야 함.
- 사용자 글꼴을 두 렌더링 경로에 오프라인 적용하는 방법과 글꼴 라이선스 확인이 필요함.
- 최근 문서 권한 유지와 마지막 위치 복원의 실제 동작을 검증해야 함.
- 앱의 저장 용량, 메모리 및 구체적 허용 표시 오차는 비교 엔진과 대표 문서의 실측 후 확정이 필요함.
- 접힌 폴더블, 화면 분할, 큰 글꼴 설정, 가로 모드 및 실기기 검증이 필요함.
