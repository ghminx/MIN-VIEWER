# Gemini Nano 로컬 시험 출력 품질 검토

- 평가일: 2026-11-18
- 기기: SM-S948N · Android 17 · `org.minviewer.app.aitrial`
- 입력: 직접 작성한 도시 녹지·열섬 본문을 포함하는 시험 PDF임. 사용자 개인 문서를 사용하지 않음.
- 방법: 실제 모델 응답을 원문과 대조해 핵심 보존·가능성과 사실 구분·원리 정확성·번역 용어·가독성을 정성 평가함. 여러 모델·반복 생성의 통계 비교나 모든 문서 품질 검증은 아님.
- 판정: **기능 호출은 확인됐으나 출력 품질을 완전 합격으로 판단하지 않음.** 설명은 짧게 줄이는 방향보다 쉬운 원리·구체적 예시·원문 연결을 유지하되 정확성 개선이 우선임.

| 작업·범위 | 확인 결과 | 한계·개선 방향 |
|---|---|---|
| 현재 페이지 요약 | 그늘·증산, 녹지 연결, 지역별 관찰 필요성의 세 요점을 포함함 | 원문의 가능성 표현을 단정적으로 바꾸는 부분이 있음. 계획된 측정과 설문 대표성 한계가 세 항목에서 생략됨. 짧은 요약의 생략과 사실 강도 변화는 구분해 점검해야 함 |
| 선택한 글 요약 | 선택한 텍스트 범위에서 요약이 반환됨 | 문장 중간에서 끝난 선택의 열 흡수 설명이 모호하게 축약됨. 완결 문장 선택과 부분 문장 선택을 나누어 재평가할 필요가 있음 |
| 현재 페이지 설명 | 원리·관계·예시·원문 연결의 긴 설명이 반환됨. 사용자 요청대로 문장 수 제한을 두지 않음 | 가능성의 단정과 원문에 없는 보충 설명의 구분을 추가 점검해야 함 |
| 선택한 글 설명 | 약 1,589자의 설명에 비유와 ‘이해를 돕기 위한 예시’를 포함함. 단순 용어 사전보다 이해를 돕는 형식임 | 에너지가 식물 내부 물 분자에서 방출되며 주변 열을 흡수한다는 취지의 문장이 포함되어 증발의 열 흡수 원리를 부정확하게 설명함. 실제 정확성 결함이며 분량 증가만으로 해결되지 않음 |
| 현재 페이지 영어 번역 | 예정된 연구와 현재 사실, 측정 조건과 설문 한계를 대체로 보존함 | ‘증산’을 더 넓은 의미인 `evapotranspiration`으로 옮기는 사례와 문장 구조 오류가 있음. 정확한 전문 용어 `transpiration`과 문법을 확인하는 재평가가 필요함 |
| 선택한 글 영어 번역 | 선택 범위만 번역함 | 원문 자체가 문장 중간에서 끝난 사례는 번역도 조각 문장으로 끝남. 모델의 출력 한도 잘림과 같은 현상으로 판정하지 않음 |

## 적용한 개선과 미확인 범위

- 설명 기본 지시는 쉬운 뜻 → 원리·관계 → 예시·비유 → 원문 연결 순서를 요구하도록 보완함. 문장 수나 임의의 짧은 길이 제한은 두지 않음.
- 원문 사실·계획·가능성 보존과 예시 구분을 지시함. 해당 지시가 모든 생성에서 지켜진다고 보장하지 않음.
- 실제 응답의 Markdown 기호가 본문에 그대로 나타나는 문제는 표시 경계에서 제목·강조·목록 스타일로 변환하고 단위 시험함. 응답 구조는 세션에 보존하며 읽기 간격을 개선함. 수정 후 실제 기기 재확인은 남음.
- 선택 범위 외의 페이지 전체를 몰래 덧붙이지 않음. 부분 문장의 문맥 부족은 사용자에게 보이는 선택 범위와 함께 평가해야 함.
- 날짜·수치·단위 전용 시험 페이지는 준비했으나 실제 AI 호출을 완료하지 못함. 단위 시험의 원문 보존 확인을 실제 번역 수치 보존 결과로 대체하지 않음.
- 실제 태블릿, 전문·장문·복잡한 표 문서, 여러 번 재생성한 일관성, 일본어 번역·후속 질문 품질은 미검증임.
- 다음 실기기 평가에서는 동일 본문의 현재 페이지·완결 문장·부분 문장에 대해 세 작업을 반복하고, 오류가 남으면 모델 한계로 명시하거나 기능 제공 범위를 다시 판단해야 함.

- 로컬 파일: `.research/ai-quality-papers/attention-is-all-you-need-1706.03762v7.pdf`임. 총 15쪽·2,215,244바이트이며 APK·Git 배포에 포함하지 않음.
- SHA-256: `bdfaa68d8984f0dc02beaca527b76f207d99b666d31d1da728ee0728182df697`임. 출처·버전·해시는 같은 폴더의 `source.json`에 보관함.
- PC에서 PDF 열기·15쪽 확인·텍스트 추출을 수행하고 4쪽 그림·수식·본문 렌더링을 확인함. 수식의 분수·위첨자가 추출 텍스트에서 흐트러지는 사례가 있어 원본 PDF와 비교해야 함. PC 추출은 Android 추출이나 Gemini Nano 품질 시험 결과가 아님.

- 각 사례는 원문 범위·페이지·추출 텍스트·작업·언어·모델 상태와 결과를 함께 기록하고 같은 범위에서 3회 반복할 예정임. 문장 중간 선택은 완결 문단 시험과 별도로 비교함.
- 영문 입력의 한국어 요약 지원 여부도 실제 API에서 확인해야 함. 입력·출력 한도 초과와 미지원 오류는 품질 성공으로 세지 않음.
- 요약은 핵심·수치·한계, 설명은 정확한 원리·구체성·예시 구분, 번역은 용어·논리·수치·조건을 각각 평가함. 하나의 종합 점수로 오류를 숨기지 않음.
- 전체 논문 일괄 요약·그림 이미지 해석은 현재 구현 범위 밖임. 이번에는 현재 페이지·선택 텍스트만 평가할 예정이며 **아직 휴대폰에서 실행하지 않음**.
