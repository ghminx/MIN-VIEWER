## 판정 기준과 실행 순서

1. 앱 빌드 커밋·기기·Android 버전·모델 준비 상태·언어·선택 범위·쪽 번호를 기록함. 현재 체크아웃과 다른 버전의 결과는 별도 기록함.
2. 앱에 추출된 글자를 먼저 원문과 대조함. 누락·읽기 순서·수식 손상이 있으면 추출 문제로 분류하고 정상 입력 번역과 별도로 기록함. 손상된 입력으로 나온 결과를 모델 번역 오류만으로 판정하지 않음.
3. 각 사례를 선택한 글 범위로 3회 실행함. 응답 시간·오류·완료 여부·실제 응답을 기록함. 미지원·한도·취소는 완료 번역으로 세지 않음.
4. 의미·누락·추가·용어·수치·단위·부정·계획·인과·문장 자연스러움을 항목별로 검토함. 문장 일치나 단순 키워드 포함만으로 합격 처리하지 않음.
5. 수치·언어쌍·부정·인과가 바뀌거나 핵심 주장이 누락되면 중대 오류로 기록함. 이해를 방해하는 전문용어 범위 변경·문법 오류도 수정 필요로 판단함. 단순 어순·자연스러운 동의어 차이는 오류로 세지 않음.
6. 각 회차의 판정은 ‘문제 없음 / 수정 필요 / 판정 불가’로 기록함. 전체 평균 점수로 중대 오류를 상쇄하지 않음. 세 번 모두 비어 있지 않은 응답이 나왔다는 사실을 품질 합격과 동일시하지 않음.

BLEU 자동 점수나 확정적인 품질 백분율은 산출하지 않음. 적은 사례·단일 기준 번역으로 전문 문서 전체의 성능을 수치화하지 않기 위함임.
