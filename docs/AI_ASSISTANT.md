# 기기 내 AI 읽기 도우미

## 범위와 빌드

- 2026-11-18 승인된 [UI 시안](mockups/ai-assistant.md)을 기준으로 구현함.
- AI 진입은 별 모양 아이콘만 사용하며 접근성 이름은 `AI 도우미`로 제공함.
- 현재 페이지와 선택한 글 각각의 요약·설명·번역을 연결함. PDF·Word의 공통 PDF 경로와 HWP·HWPX 원본 읽기를 대상으로 함. PPT 텍스트 선택·전체 문서·이미지 입력·장문 분할은 활성화하지 않음.
- `aiTrial` 빌드만 Google ML Kit GenAI 의존성과 UI를 포함함. 패키지 접미사 `.aitrial`을 사용해 기존 앱 데이터와 분리함.
- `debug`·`release`는 AI 미포함 경로를 사용함. 버전 1.1.4와 공개 APK를 유지하며 AI 시험 APK는 로컬에만 생성·설치함.
- 개인 시험도 Google API 약관 적용 대상임. 공개 배포 허용 여부를 이번 구현으로 확정하지 않음.

## 창 크기별 배치

| 현재 창 | 배치 | 검증 항목 |
|---|---|---|
| 휴대폰 세로 | 문서 위·AI 아래 | 원문 대상 위치, 결과 스크롤, 키보드·시스템 여백 |
| 휴대폰 가로 | 문서 왼쪽·AI 오른쪽, 패널 크게 보기 제공 | 낮은 높이에서 실행·취소·결과 접근 |
| 태블릿 세로 | 충분한 본문 폭 확보 시 오른쪽, 좁으면 아래 | 화면 방향만으로 기기를 구분하지 않음 |
| 태블릿 가로 | 문서 왼쪽·AI 오른쪽 | 페이지 목록과 AI 동시 표시 방지 |

회전 중 원문 범위·결과·진행 요청은 메모리 세션으로 유지함. 문서를 닫으면 요청을 취소하고 원문·대화를 폐기함. 디스크·로그에 원문이나 응답을 저장하지 않음.

- 실제 배치 기준: 문서 창 폭 720dp 이상 또는 폭 600dp 이상·높이 480dp 미만이면 오른쪽 패널을 사용함. 그 외에는 아래 패널을 사용함.
- 아래 패널 높이는 준비 상태 약 64%, 결과 약 76%, 크게 보기 약 86%임. 낮은 창의 크게 보기와 키보드로 높이가 부족한 창에서는 문서를 잠시 숨기고 패널 공간을 확보함.
- 높이 420dp 미만에서는 작업 탭을 작업 선택 메뉴로 바꿈. 소프트 키보드·큰 글자·실제 태블릿에서의 사용성은 추가 확인 대상임.
- 글자 선택 메뉴는 `복사 / 모두 선택 / 요약 / 설명 / 번역`으로 구성함. `모두 선택`은 현재 페이지를 대상으로 하며 다른 본문 위치를 누르면 선택을 해제함.
- 아이콘이나 선택 메뉴는 원문 미리보기만 열며 작업 실행은 사용자가 별도로 선택함. 범위 선택에서 현재 페이지와 선택한 글을 전환할 수 있음.

## 기본 지시와 모델 연결

- 요약·설명·번역·질문은 Prompt API를 사용함. 사용자가 요청한 자연스러운 결과 형식을 위해 세 항목으로 고정되는 Summarization 경로와 미사용 의존성을 제거함. 이전 실기기 페이지 요약 결과는 변경 전 전용 API의 결과이며, 새 페이지 요약 경로의 실제 품질·속도는 재검증 대상임.
- Prompt API에 작업별 기본 지시와 구분된 원문을 전달함. 기기 모델 준비와 입력·출력 한도·취소 처리는 같은 경로를 사용함.
- 요약 지시: 원문 핵심을 한국어로 간결하게 정리하되 형식과 항목 수를 고정하지 않음. 수치·조건·불확실성을 유지하고 근거 없는 정보를 추가하지 않도록 요청함.
- 설명 지시: 처음 접하는 사용자가 이해하도록 쉬운 뜻 → 원리·관계 → 예시·비유 → 원문 연결 순으로 구체적으로 설명함. 문장 수로 분량을 임의 제한하지 않음. 예시는 원문 사실과 구분해 표시하며 확인되지 않은 사실을 추측하지 않도록 요청함.
- 번역 지시: 선택 언어로 번역문만 반환함. 이름·숫자·단위·문단과 의미를 보존하고 해설을 추가하지 않도록 요청함.
- 문서 안의 지시는 분석 대상 데이터로 취급하며 앱 작업 지시를 바꾸지 않도록 구분함. 모델의 준수는 품질 시험 대상이며 보장으로 표현하지 않음.
- Gemini Nano 런타임 상태를 확인하고 미지원·준비 필요·한도·안전 필터·입력 길이 오류를 표시함. 자동 재전송과 클라우드 대체는 하지 않음.
- 원문 쪽 번호는 요청 당시 앱이 기록함. 모델이 생성한 번호를 근거 페이지로 신뢰하지 않음.
- 입력을 자동으로 자르지 않음. Prompt 입력 토큰을 확인하고 출력 공간이 부족하면 짧은 범위를 요청함. 출력 토큰 한도에 도달한 미완성 응답은 결과로 표시하지 않음.
- 모델 준비가 필요하면 별도 확인 후 AICore 다운로드를 시작함. 다운로드 완료만으로 문서 처리를 자동 실행하지 않음. 처리 중 취소와 늦은 응답 무시를 제공함.
- AI 세션에는 응답의 제목·강조 구조를 보존함. 표시 경계에서 소제목·강조·목록을 네이티브 텍스트 스타일로 변환하며 복사 버튼은 화면에서 읽는 일반 텍스트를 복사함. 번역문은 의미·기호 보존을 위해 동일 변환을 적용하지 않음.

## 결과 읽기 UI 개선 · 2026-11-18

| 요소 | 기존 | 개선 |
|---|---|---|
| 결과 제목 | 작업명과 본문 크기 차이가 작았음 | ‘핵심 요약·쉽게 풀어보기·번역’ 제목 21sp, 대상 범위·쪽 번호 12sp로 구분함 |
| 본문 | 15sp의 단일 텍스트 표시였음 | 16sp·줄 간격 1.5배, 시스템 글자 크기 반영을 유지함 |
| 문단·목록 | 연속 목록과 소제목 구분이 약했음 | 문단과 각 목록 항목 사이 빈 줄, 목록의 이어지는 줄 들여쓰기, 소제목 약 18sp·Pretendard SemiBold를 적용함 |
| 원문 미리보기 | 결과 위에 긴 선택 원문이 계속 표시됐음 | 실행 전 미리보기는 유지하고 결과에서는 대상 범위·쪽 번호만 표시함. 원문 이동 버튼을 유지함 |
| 결과 도구 | 결과 직후 버튼·안내가 붙어 있었음 | 본문 아래 24dp 여백, 버튼 간 8dp 간격·48dp 높이, 안내문 12sp와 별도 여백을 적용함 |

- UI/UX 스킬의 본문 가독성·간격·정보 계층 지침을 참고함. 검색 결과의 터미널용 글꼴 제안은 문서 읽기 UI와 맞지 않아 적용하지 않음. 기존 Pretendard·색상·휴대폰 아래 패널·태블릿 옆 패널 배치를 유지함.
- 기본은 자연스러운 문단으로 작성하고 소제목·강조·목록은 필요한 경우에만 요청함. 여러 요점·비교는 목록, 절차는 번호를 사용할 수 있으나 짧은 답변의 소제목과 항목 수를 강제하지 않음. 설명 분량을 짧게 제한하거나 화면 표시 단계에서 결과를 다시 요약하지 않음.
- 화면 표시에는 HTML·WebView·링크 실행을 사용하지 않으며 별도 Markdown 의존성을 추가하지 않음. 제목·강조·목록의 한정된 표시 규칙만 적용함.
- 실패 확인 후 AI 세션의 응답 구조 보존을 수정함. 결과 형식 시험 4개로 제목·목록·수치·긴 설명·문단·번역 기호 보존을 확인함.
- 웹 시안의 본문 16px·줄 간격 1.5배·문단 여백 24px와 10개 가로·세로/테마 조합을 검사함. 웹 이미지는 고정 응답 시안이며 Android 네이티브 화면이나 모델 품질 검증을 대신하지 않음.
- 로컬 AI 빌드와 AI 미포함 Debug 단위 시험을 수행함. 이번 읽기 UI 변경의 실제 휴대폰·태블릿 검증과 변경된 지시의 Gemini Nano 출력 확인은 재연결 후 진행해야 함. 공개 버전·APK는 유지함.

### 다음 연결 시 우선 조치

- 휴대폰 창 크기 모의 시험 도중 연결이 끊겨 `wm size`, `wm density`, 회전 설정의 원복 완료를 확인하지 못함.
- 추가 조작 전에 현재 `wm size`, `wm density`, `user_rotation`, `accelerometer_rotation`을 조회하고 시험에서 남긴 화면 크기·밀도 오버라이드를 해제해야 함. 원래 회전 값은 영속 기록되지 않아 사용자 설정 확인이 필요함.
- 중단 기록은 로컬 `.research/ai-ui-physical/restore-required.json`에 보관함. 후속 창 시험은 원래 설정을 파일에 먼저 기록하고 연결 종료 시에도 재연결 후 복원할 수 있도록 시험 도구를 보완함. 기록 기반 복원은 PC의 연결 종료 모의 시험을 통과함.
- 사용자의 요청에 따라 휴대폰 없이 가능한 검증과 문서화 후 실기기 작업을 보류함. 설정 원복 완료 전 창 시험을 다시 실행하지 않음.

## 기기 미연결 검증·코드 검토 후 보완

- 상세 근거·파일 위치·검증 범위는 [로컬 AI 코드 검토](AI_OFFLINE_REVIEW.md)를 따름.
- 원문 로딩도 문서 수명의 세션에서 관리함. 회전은 이전 화면의 원문 콜백을 무효화하고 문서 준비 신호 이후 다시 읽으며, 진행 중인 AI 추론·완료 결과·질문 초안은 유지함.
- 추가 질문의 재시도는 같은 원문·질문·이전 답변을 사용함. 질문 응답을 번역·요약 제목으로 표시하지 않음. 패널 숨김은 완료·오류 상태를 보존하고 문서 종료는 원문·응답·선택 글·초안·재시도 문맥을 비움.
- 창 폭 360dp 미만·높이 420dp 미만·글자 배율 1.3 이상이면 축약형 작업 선택을 사용함. 글자 배율 1.5 이상·높이 600dp 미만에서는 패널 전체 영역을 사용함. 최소 터치 높이 48dp를 유지하면서 텍스트 버튼 높이는 내용에 맞춤.
