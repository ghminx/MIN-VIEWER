# MIN VIEWER v1.1.3

Android 10 이상 ARM64 기기용 배포 버전임. 앱 버전은 1.1.3, 내부 설치 번호는 12임. 기존 배포 키로 서명하여 앱 삭제 없이 업데이트할 수 있음.

## 변경 사항

- 외부 PDF·HWP·HWPX·DOCX·PPTX·XLSX·CSV 파일을 읽기 미리보기로 열고, `문서에 추가`를 선택하면 앱 내부에 원본 사본을 보관함.
- 같은 내용의 문서를 다시 추가하면 기존 문서를 열거나 새 사본을 추가할 수 있음. 보관된 문서에서 필기를 시작하면 기존 항목에 연결함.
- 읽기용 보관 문서도 문서 관리에서 백업·삭제하고 설정에서 복원할 수 있음. 필기 문서는 기존 백업·PDF 출력 기능을 유지함.
- 원본 접근 권한이 사라졌을 때 오류를 안내하고, 중단된 임시 파일 정리와 동시 필기 연결의 안전성을 보강함.
- 암호 Word·PPT 미리보기와 임시 사본 정리를 지원함. 보관 후 다시 열 때 비밀번호를 다시 입력하며 암호 문서 필기는 지원하지 않음.

## 검증과 제한

- 자동 검사 22개와 PDF 출력 판정 회귀 시험이 통과함. 릴리스 빌드·Lint는 오류 0개, 경고 74개이며 릴리스 단위 시험 작업은 NO-SOURCE임.
- 태블릿의 디버그 시험판에서 7개 형식의 보관·재열기, 5개 형식의 필기와 백업, 읽기 문서 백업 복원, 외부 열기·공유와 오류 처리를 대표 시험 문서로 확인함. 상세 결과는 [테스트 내역](https://github.com/ghminx/MIN-VIEWER/blob/v1.1.3/docs/테스트내역.md)을 따름.
- Galaxy 휴대폰에는 기존 문서·필기 데이터를 유지하는 방식으로 릴리스 APK를 설치함. 이번 휴대폰 작업은 설치 확인만 수행했으며 앱 조작 검증은 포함하지 않음.
- 문서 보관·복원은 원본당 최대 512MiB임. 실제 저장 공간 고갈, 모든 복잡 문서 및 실제 S펜 사용감·손바닥 인식은 추가 확인 대상임.
