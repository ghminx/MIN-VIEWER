# 읽기 미리보기와 문서 보관 계획

## 확정된 사용자 동작

- 외부 파일은 먼저 읽기 미리보기로 열고, 사용자가 `문서에 추가`를 선택하면 원본 사본을 앱 내부에 보관함.
- PDF·HWP·HWPX·DOCX·PPTX 미리보기는 세로 스크롤·확대를 제공함. XLSX·CSV는 표 이동과 시트 선택을 유지함.
- 필기와 기존 문서 관리 기능은 추가 후 사용함. XLSX·CSV는 읽기만 제공함.
- 추가할 때 파일 내용의 SHA-256을 계산함. 이미 같은 내용의 보관 사본이 있으면 기존 문서 열기 또는 새 사본 추가를 선택함. 내용이 다르면 이름이 같아도 새 버전으로 보관함.
- 보관된 문서를 필기 상태로 전환할 때 홈 항목은 하나로 유지함. 전환 실패 시 읽기용 사본을 보존함.
- 보관 문서는 홈에서 삭제·문서별 백업·복원을 제공함. 외부 원본과 기존 최근 기록·필기 문서는 유지함.
- 외부 앱의 열기·공유로 받은 문서도 미리보기·추가를 제공함. 일시 URI 권한 만료와 실패를 안내함.

## 구현 및 검증 경계

- 앱 내부 원본 사본의 식별·중복 확인·원자적 저장·정리와 기존 필기 보관의 식별 연결을 설계함. 파일별 별도 사본과 필기 자동 저장을 구분함.
- 백업 포맷은 기존 필기 백업의 복원 호환성을 유지하고 읽기용 원본의 형식·무결성을 검증함. 실패·취소 시 기존 문서와 필기를 변경하지 않음.
- SHA-256 계산과 대용량 복사는 작업 큐에서 수행함. 사용자 취소, 공간 부족 및 중단 후 임시 파일 정리를 검증함.
- 테스트 경계: 실제 화면의 미리보기→추가→외부 시험 원본 삭제→앱 재시작→재열기·필기 전환, 저장소의 공간 부족·중단·중복·백업 복원임.
- 연결된 기기에서 별도로 생성한 시험 파일만 사용함. 사용자의 원본·보관 문서·필기는 삭제하지 않음.
- 버전과 공개 APK는 유지하고 기존 배포 키와 호환되는 디버그 시험판으로 확인함.

## 진행 상태

- 7개 형식의 읽기 미리보기와 내부 사본 추가, SHA-256 기반 중복 선택, 문서별 백업·복원 및 사본 삭제가 구현됨.
- PDF·한글·Word·PPT의 필기 전환은 보관 항목과 연결되며, 표 문서는 읽기와 기존 표 탐색을 유지함.
- 이전 필기 백업으로 복원한 문서도 원본 내용 기준 중복 확인 대상에 포함됨.
- 암호 Word·PPT 미리보기는 비밀번호 입력 후 앱 캐시에 임시 PDF를 사용함. 정상 종료 또는 다음 앱 실행 시 사용하지 않는 임시 사본을 정리함. 보관 후 다시 열 때 비밀번호 재입력이 필요하며 암호 문서 필기는 지원하지 않음.
- 문서 보관과 복원은 원본당 최대 512 MiB로 제한됨. 제한 초과 시 오류를 안내하며 기존 보관 문서는 유지됨.
- 저장 준비 중 프로세스 종료 시 다음 보관함 갱신에서 중단된 준비 파일을 정리함. 다른 프로세스에서 진행 중인 저장은 유지함.
- 태블릿의 대표 시험과 제한 사항은 `docs/테스트내역.md`에 기록함. 실제 저장 공간 고갈과 실제 S펜 입력 시험은 이번 검증에 포함되지 않음.
