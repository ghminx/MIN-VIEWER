# MIN VIEWER v1.1

Android 10 이상 ARM64 기기용 문서 읽기·필기 앱임. 앱 표시 버전은 **1.1**, 내부 설치 번호는 **9**임. 기존 공개 APK와 같은 키로 서명함.

## 주요 변경

- PDF·HWP·HWPX·DOCX·PPTX 필기를 제공함. 원본을 보존하고 필기용 사본·고정 배경·획 데이터를 기기에 자동 저장하며 다시 열 때 복원함.
- 펜 색상·굵기, 형광펜, 획 지우개, 올가미 선택·이동·복제·삭제·크기 조절과 실행 취소/다시 실행을 제공함. 펜 버튼을 누르는 동안 지우개로 전환함.
- 올가미 선택 획을 다른 페이지로 옮기고, 길게 눌러 복사·잘라내기·붙여넣기·삭제할 수 있음. 문서 내부 클립보드는 문서를 닫으면 비워짐.
- 필기 포함 PDF 사본 내보내기와 원본·배경·필기 데이터의 수동 백업·복원을 제공함. 원본 글자 검색과 벡터·이미지 품질을 최대한 유지함.
- 메인 화면·페이지 목록·필기 도구를 개편하고 Pretendard UI 글꼴을 적용함. PDF·한글·Word·PowerPoint의 첫 페이지 썸네일과 문서별 형식 필터를 제공함.
- PDF·한글·Word의 한쪽/두쪽 배치와 페이지 넘김/세로 스크롤을 분리함. 세로 창은 한쪽, 가로 창은 마지막 배치를 유지하며 표지 단독 표시를 선택할 수 있음.
- 목록·읽기/필기 전환의 확대율·위치 초기화, 두쪽 확대 종료 점프와 페이지 넘김을 개선함. 원본 한글·PowerPoint 읽기 화면도 드래그를 따라 이동함.

## 설치와 데이터

- 기존 공개 버전은 APK를 열어 덮어쓰기 업데이트함. 기본 개발 키로 서명한 디버그 앱은 서명이 다르므로 업데이트할 수 없음.
- 앱 삭제 시 내부 사본·필기·최근 기록도 삭제됨. 수정 가능한 필기를 다른 기기로 옮기려면 문서 관리에서 수동 백업을 사용함.
- 광고·로그인·문서 업로드와 INTERNET 권한이 없으며 문서를 기기에서 처리함.

## 검증 범위

- API 35 에뮬레이터와 Galaxy Tab S10 Ultra(Android 16)에서 문서 열기·탐색, 필기 저장·복원, 올가미 편집, 페이지 배치·목록 전환과 핀치 확대를 검증함.
- 한쪽/두쪽 × 페이지 넘김/세로 스크롤 × 목록 닫힘/열림의 8가지 조합에서 읽기↔필기 전환 후 200% 유지와 목록 반복을 확인함.
- 관련 자동 시험 18개와 릴리스 빌드·Lint를 통과함. Lint 오류 0개·경고 67개임. 구현·실기기 검증 내역은 [필기 검증 기록](https://github.com/ghminx/MIN-VIEWER/blob/v1.1/docs/ANNOTATION_PLAN.md)을 따름.
- 배포 APK를 공개 1.0.5 위에 설치해 최근 문서·마지막 페이지 보존을 확인함. 배포용 APK로 7개 형식 열기, 올가미·클립보드·저장/재열기와 고지 화면을 시험함.
- 실제 태블릿의 기존 필기를 유지한 채 1.1로 업데이트함. 필기 포함 PDF 출력에서 원본 5쪽의 글자와 파란 벡터 필기가 유지됨을 확인함.

## 알려진 제한

- 실제 손으로 사용하는 S펜 필기감·손바닥 인식, 모든 장시간 부하 조건·복잡 문서·기기 조합을 검증한 결과는 아님.
- 암호 문서·구형 DOC/PPT·XLSX·CSV는 새 필기 대상에서 제외함. PDF 검색·암호 입력은 Android 15 이상에서 제공함.
- 한글·Word·PowerPoint의 일부 글꼴·표·수식·그림은 원본과 차이가 있을 수 있음. 문서 내용 편집·OCR·클라우드 동기화는 제공하지 않음.
- 원본 PPTX 읽기의 넓은 창 목록은 기존 방식대로 문서 위에 표시되어 왼쪽 일부를 가릴 수 있음. PDF 및 공통 필기 화면은 목록과 문서 영역을 분리함.
