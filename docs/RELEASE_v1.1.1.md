# MIN VIEWER v1.1.1

1차 개발 마무리 패치임. Android 10 이상 ARM64 기기용이며 앱 버전은 1.1.1, 내부 설치 번호는 10임. 기존 배포 키로 서명하여 1.1 위에 데이터 삭제 없이 업데이트 가능함.

## 변경 사항

- PDF 출력 시험에서 필기 누락·위치 변경을 놓치던 판정을 보완함. 배경 대비 페이지·텍스트와 추가 획의 위치·색상을 비교함.
- 기기·실행 식별자·요구 형식·완료 상태를 확인해 이전 실행이나 부분 성공 결과가 복원 시험에 사용되지 않도록 함.
- 출력·복원 시험의 시스템 파일 선택 절차를 공유함.
- 페이지 간 필기 이동과 붙여넣기의 크기 변환 계산을 기존 필기 선택 모듈로 모음. 원본 문서와 저장 형식은 유지함.
- 태블릿·휴대폰 공통 절차와 기기별 시험 내역을 `docs/테스트내역.md`에 정리함.

## 검증과 제한

- 자동 시험 19개와 PDF 출력 판정 회귀 시험 통과. 릴리스 빌드와 Lint 오류 0개·경고 67개 확인됨.
- 실제 태블릿 최종 시험의 구체적 범위는 [테스트 내역](https://github.com/ghminx/MIN-VIEWER/blob/v1.1.1/docs/테스트내역.md)에 기록함.
- 태블릿 배포 APK에서 PDF·PPTX·DOCX·HWP·HWPX 필기·백업·출력·복원 후 재열기 및 올가미·클립보드·서로 다른 페이지 크기 이동·크기 초과 거부 시험을 통과함.
- 실제 S펜 사용감·손바닥 인식, 모든 복잡 문서와 장시간 조건을 보장하는 결과는 아님. 기존 지원 제한은 [v1.1 안내](https://github.com/ghminx/MIN-VIEWER/releases/tag/v1.1)를 따름.
