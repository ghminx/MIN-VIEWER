# MIN VIEWER v1.1.2

실사용 검증을 위한 현재 배포 기준 버전임. Android 10 이상 ARM64 기기용이며 앱 버전은 1.1.2, 내부 설치 번호는 11임. 기존 배포 키로 서명해 앱 삭제 없이 업데이트 가능함.

## 변경 사항

- PDF·PPTX 발표 모드를 추가함. 현재 페이지부터 도구와 시스템 표시줄을 숨겨 한 장씩 표시하고, 원본 비율을 유지하며 스와이프·가장자리 탭으로 이동함. 종료 버튼과 기기 뒤로 가기를 제공하고 회전 후 현재 페이지와 발표 모드를 복원함.
- 4:3 발표 자료의 화면 맞춤을 방해하던 시스템 표시줄 여백과 발표 종료 터치가 다음 페이지 이동으로 처리되던 문제를 수정함.
- PPTX 최초 읽기·필기·필기 후 읽기의 더보기 메뉴와 순서를 통일함. 준비되지 않은 필기 문서 작업은 비활성으로 표시함. PPT는 한 슬라이드 탐색을 유지하고 PDF용 두쪽·스크롤·표지 설정을 제외함.
- PPT 스와이프 속도를 고정된 창 좌표에서 측정하여 짧고 빠른 스와이프가 누락되던 문제를 수정함. 거리·속도 임계값을 낮추지 않음.
- 한글 페이지 전환 중 먼저 종료된 페이지 애니메이션이 잠시 원위치에 나타날 수 있는 부분을 수정함.

## 검증과 제한

- 자동 검사 21개와 PDF 출력 판정 회귀 시험이 통과함. 릴리스 빌드와 Lint 오류 0개·경고 67개를 확인함. Kotlin 단위 시험 작업은 시험 소스가 없어 별도 실행 항목이 없음.
- 디버그 앱으로 실제 Galaxy Tab S10 Ultra에서 16:9·4:3 PDF와 PPT 출력 PDF의 원본 비율·화면 맞춤·잘림·회전·앞뒤 이동을 확인함. PPT 메뉴는 가로·세로에서 검증하고 PDF·HWP·DOCX·PPTX에 같은 스와이프를 입력해 비교함.
- 실제 태블릿의 배포 APK에서 PPT 메뉴·스와이프·16:9 PDF 발표 모드와 PPTX 필기 저장·백업·PDF 출력·복원 후 필기 표시 검사가 통과함.
- 배포 APK에서 확인한 범위와 반복 절차는 [테스트 내역](https://github.com/ghminx/MIN-VIEWER/blob/v1.1.2/docs/테스트내역.md)에 기록함.
- 발표 모드는 정적 페이지 표시이며 PPT 개체 애니메이션·동영상 재생·자동 넘김은 이번 범위에서 제외함. 문서와 화면의 비율이 다르면 여백이 남으며, 발표 모드 진입·종료 시 확대율은 100%로 초기화됨.
- 사용자 HWP 문서의 번갈아 깜빡임 완전 해소 여부, 이번 변경의 휴대폰·외부 화면 출력, 실제 S펜 사용감·손바닥 인식과 모든 장시간 조건은 추가 실사용 확인 대상임.
